# steminmusic.com

Static website for Stemin. Every page is a plain `index.html` (home at the root, others in `about/`, `live/`, `music/`, `visuals/`, `contact/`, `policy/`, `thanks/`). Shared styling: `style.css`; scripts: `main.js`.

- **Photos** live in `img/`. Each photo also has a `-800` version used on phones.
- **Hosting:** Cloudflare Pages, connected to this repository. Every change pushed here goes live automatically.
- **Upcoming shows** load from Bandsintown.
